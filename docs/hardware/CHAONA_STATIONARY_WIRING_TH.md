# Grow a Garden: ผังต่อ Stationary ESP32

เอกสารนี้เป็นชุดต่อสำหรับสถานีวัดประจำแปลง โดยใช้ AF333/SN-3002-TR-NPK-N01 ที่ทดสอบแล้วว่าอ่านค่า N-P-K ผ่าน RS485 ได้

## ข้อสำคัญก่อนต่อไฟ

- AF333 รุ่นนี้เป็นเซ็นเซอร์ NPK เท่านั้น อย่าแสดงว่าอ่าน pH, EC, อุณหภูมิ หรือความชื้นได้
- ห้ามต่อ 12V เข้าขา ESP32, GPIO, MAX485 หรือเซ็นเซอร์ความชื้นโดยตรง
- ตั้ง Buck converter ด้วยมัลติมิเตอร์ให้ได้ 5.00V ก่อนต่อเข้าขา VIN/5V ของ ESP32
- ถ้าใช้ MAX485 โมดูล 5V ให้ลดแรงดันขา RO ก่อนเข้า ESP32 ตามตารางด้านล่าง หรือเปลี่ยนเป็น MAX3485 3.3V
- สายของเซ็นเซอร์แต่ละร้านอาจไม่เหมือนกัน ห้ามเชื่อจากสีสายอย่างเดียว ให้ยึดฉลาก V+, GND, A, B
- เซ็นเซอร์ฝนและความชื้นยังไม่ทราบรุ่นแน่ชัด ผังนี้จึงใช้ rain gauge แบบหน้าสัมผัส/กระดก และ moisture แบบ analog 0-3.3V เท่านั้น

## ภาพรวมระบบไฟ

```text
แผงโซลาร์ 20W
      │ PV+ / PV-
      ▼
[Solar charge controller]
      │ BAT+ / BAT-
      ▼
[แบตเตอรี่ 12V 9Ah]
      │
      ├── LOAD+ ── ฟิวส์ 1A ── สวิตช์ ──┬── AF333 V+ (5-30V)
      │                                  └── Buck IN+
      └── LOAD- ─────────────────────────┬── AF333 GND
                                         ├── Buck IN-
                                         ├── ESP32 GND
                                         ├── RS485 GND
                                         ├── Moisture GND
                                         └── Rain GND

[Buck OUT 5.00V] ───────── ESP32 VIN/5V
                  └─────── MAX485 VCC (ถ้าเป็นโมดูล 5V)

หมายเหตุ: ต่อกราวด์ทุกส่วนร่วมกัน แต่ห้ามเอา 12V ไปเข้าขา 3V3 หรือ GPIO
```

ควรใส่ฟิวส์ใกล้ขั้วบวกแบตเตอรี่ที่สุด และเก็บวงจรแปลงไฟในกล่องกันน้ำโดยแยกจากน้ำฝนและสายเสาอากาศ

## AF333 + MAX485 + ESP32

โค้ดใช้ HardwareSerial UART2 ดังนี้:

| ESP32 | MAX485 | หมายเหตุ |
|---|---|---|
| GPIO17 | DI | ข้อมูลส่งไปเซ็นเซอร์ |
| GPIO16 | RO | ข้อมูลกลับจากเซ็นเซอร์ |
| GPIO4 | DE และ RE ผูกเข้าด้วยกัน | ควบคุมทิศทาง RS485 |
| GND | GND | กราวด์ร่วม |
| 5V/VCC | VCC | เฉพาะโมดูลที่รับ 5V |
| A | AF333 A | ห้ามสลับกับ B |
| B | AF333 B | ห้ามสลับกับ A |

ถ้า MAX485 ใช้ไฟ 5V ให้ต่อ RO ผ่านตัวแบ่งแรงดัน:

```text
MAX485 RO ── 2.2kΩ ──┬── ESP32 GPIO16
                     └── 3.3kΩ ── GND
```

ทางเลือกที่เหมาะกับ ESP32 กว่า: ใช้ MAX3485 ซึ่งเป็น RS485 ระดับ 3.3V และต่อ RO เข้า GPIO16 ได้ตรงตามสเปกของโมดูล

ค่าที่ล็อกไว้ในโค้ดตามเซ็นเซอร์ของคุณ:

```text
baud     = 4800
address  = 1
function = 0x03
register = 0x0004
จำนวน    = 3 registers (N, P, K)
```

## Soil moisture แบบ analog

ใช้ได้เฉพาะโมดูลที่ระบุว่าไฟเลี้ยงและเอาต์พุตเข้ากับ ESP32 ได้ โดยต่อ:

```text
Moisture VCC ── ESP32 3V3
Moisture GND ── ESP32 GND
Moisture AO  ── ESP32 GPIO34
```

GPIO34 เป็นขา input-only และเหมาะกับ ADC แต่ห้ามนำ AO ที่เป็น 5V เข้า GPIO34 เด็ดขาด หากโมดูลของคุณมีแต่ไฟ 5V หรือ AO สูงกว่า 3.3V ให้หยุดก่อนและส่งรูป/รุ่นมาเพื่อคำนวณตัวแบ่งแรงดันที่ถูกต้อง

ในไฟล์ `.ino` ค่าแห้งและเปียกเริ่มต้นเป็นเพียงค่าทดสอบ:

```cpp
MOISTURE_DRY_RAW = 3000
MOISTURE_WET_RAW = 1500
```

ให้จดค่า `analogRead` ตอนดินแห้งและตอนดินเปียกจริง แล้วแก้สองค่าก่อนใช้คำแนะนำการให้น้ำ

## Rain gauge แบบ tipping bucket / dry contact

ถ้าเป็น rain gauge ที่มีหน้าสัมผัสสวิตช์ ให้ต่อ:

```text
Rain wire 1 ── ESP32 GPIO27
Rain wire 2 ── ESP32 GND
```

โค้ดใช้ `INPUT_PULLUP` และนับขอบสัญญาณ FALLING จึงไม่ต้องจ่าย 12V ให้หน้าสัมผัส

ค่าเริ่มต้นในโค้ดคือ `0.2794 mm/ครั้ง` ซึ่งเป็นค่าที่พบบ่อยของถัง 0.01 นิ้ว แต่ต้องเปลี่ยนเป็นค่าตาม datasheet ของรุ่นจริง ถ้าเป็น rain sensor แบบแผ่นตรวจหยดน้ำ, โมดูล analog หรือโมดูลที่มีไฟ 5V ผังนี้ใช้ไม่ได้โดยตรง

## MQTT ที่ส่งไปแอป

```text
broker: broker.emqx.io
port:   1883
topic:  farm/esp32/sensors
device: grow-station-01
```

ตัวอย่างเมื่ออ่านได้:

```json
{
  "device_id": "grow-station-01",
  "source": "stationary",
  "modbus_ok": true,
  "sensor_status": "read",
  "nitrogen": 10,
  "phosphorus": 5,
  "potassium": 8,
  "moisture": 42,
  "rain_tips": 3,
  "rain_mm": 0.838,
  "rssi": -55
}
```

ถ้า AF333 อ่านไม่ได้ โค้ดจะส่ง `modbus_ok:false` และจะไม่สร้างค่า NPK ปลอม แอปควรแสดงว่า sensor ยังไม่อ่านได้

## ขั้นตอนทดสอบที่ปลอดภัย

1. ยังไม่ต่อ AF333, moisture หรือ rain แล้วจ่ายไฟจาก USB ให้ ESP32 ก่อน
2. เปิด Serial Monitor ที่ `115200` และตั้งค่า Wi-Fi ผ่าน `Grow-Station-Setup`
3. ถอดไฟออก วัด Buck OUT ให้ได้ 5.00V แล้วค่อยต่อ ESP32 VIN/5V
4. ต่อ MAX485 และ AF333 ตามตาราง ตรวจ A/B และ GND สองรอบ
5. จ่ายไฟให้ AF333 ตามฉลาก 5-30V โดยใช้สายจาก LOAD หลังฟิวส์/สวิตช์
6. ต้องเห็น `N = ... | P = ... | K = ...` ก่อนจึงต่อ moisture
7. ต่อ moisture เฉพาะเมื่อยืนยันว่า AO ไม่เกิน 3.3V
8. ต่อ rain gauge แบบ dry contact ที่ GPIO27/GND และทดสอบกดสวิตช์หนึ่งครั้ง
9. เมื่อเห็น `MQTT connected` และ `MQTT published` ให้เปิดแอปและดูอุปกรณ์ `grow-station-01`

ถ้าเห็นค่า NPK เป็นศูนย์ทั้งสามช่อง อาจเป็นค่าที่เซ็นเซอร์รายงานจริงหรือ register ไม่ตรง ห้ามสรุปว่าดินขาดธาตุจนกว่าจะเทียบกับการตรวจห้องแล็บหรือคู่มือรุ่นเซ็นเซอร์
