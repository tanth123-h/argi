# คู่มือประกอบ Chaona ภาษาไทย

คู่มือนี้ใช้กับอุปกรณ์ 2 ชุด:

1. ชุดพกพา Handheld สำหรับเดินวัดดินหลายจุด
2. ชุดติดตั้งประจำที่ Stationary สำหรับส่งข้อมูลผ่าน Wi-Fi/MQTT

## คำเตือนก่อนต่อไฟ

- ถอดสาย USB ของ ESP32 ออกก่อนต่อไฟภายนอกทุกครั้ง
- ห้ามต่อแบตเตอรี่ 12V เข้าขา `VIN`, `5V` หรือ `3V3` ของ ESP32 โดยตรง
- ต้องปรับ Buck Converter ให้ได้ **5.0V ด้วยมัลติมิเตอร์** ก่อนต่อ ESP32
- ห้ามเดาสีสาย หากสีไม่ตรงกับคู่มือของร้าน ให้หยุดและถามผู้ขายก่อน
- ต่อไฟตามขั้ว `+` และ `-` เท่านั้น การต่อกลับขั้วอาจทำให้เซ็นเซอร์เสีย
- ใส่ฟิวส์ 1A ใกล้ขั้วบวกของแบตเตอรี่
- อย่าเสียบหรือถอดสาย RS485 ขณะที่ระบบมีไฟอยู่

## สิ่งที่ยืนยันจากรูปอุปกรณ์

หัววัดในรูปมีฉลากรุ่น `SN-3002-TR-NPK-N01`, `DC 5-30V` และ `RS485 A/B`
จึงควรถือว่าเป็นเซ็นเซอร์ **NPK เท่านั้น** ได้แก่:

- ไนโตรเจน (N)
- ฟอสฟอรัส (P)
- โพแทสเซียม (K)

ห้ามให้แอปแสดงค่าความชื้น อุณหภูมิ EC หรือ pH จากเซ็นเซอร์ตัวนี้ เว้นแต่คู่มือ
ของ AF333 รุ่นที่คุณซื้อจะระบุชัดเจนว่ารองรับค่าเหล่านั้น

เซ็นเซอร์ 2 ตัวให้แยกใช้คนละชุด:

```text
เซ็นเซอร์ตัวที่ 1 -> MAX485/MAX3485 -> ESP32 Handheld
เซ็นเซอร์ตัวที่ 2 -> MAX485/MAX3485 -> ESP32 Stationary
```

ต้องมีโมดูล RS485 **2 ตัว** ถ้าตอนนี้มี MAX485 เพียงตัวเดียว ต้องเพิ่มอีกหนึ่งตัว
ก่อนทำชุด Stationary ห้ามต่อเซ็นเซอร์สองตัวเข้ากับ MAX485 ตัวเดียวแบบสุ่ม

## สีสายเซ็นเซอร์

สีที่ตรงกับเซ็นเซอร์ NPK กลุ่มนี้โดยทั่วไปคือ:

| สีสาย | หน้าที่ | แรงดัน/สัญญาณ |
|---|---|---|
| น้ำตาล | VCC หรือไฟบวก | 5-30V DC |
| ดำ | GND หรือไฟลบ | 0V |
| เหลือง | RS485 A | สัญญาณข้อมูล |
| น้ำเงิน | RS485 B | สัญญาณข้อมูล |

สีสายไม่ใช่มาตรฐานสากล ให้ตรวจสอบกับคู่มือ AF333 ก่อนจ่ายไฟ หากไม่แน่ใจ
ให้ใช้มัลติมิเตอร์ตรวจสายหรือส่งรูปสายและฉลากด้านหลังให้ผู้ขายยืนยัน

## ชุด Stationary: แผนผังไฟหลัก

```text
แผงโซลาร์เซลล์ 20W
    + ---------------------- PV+ ของ Solar Controller
    - ---------------------- PV- ของ Solar Controller

แบตเตอรี่แห้ง 12V 9Ah
    + ---------------------- BAT+ ของ Solar Controller
    - ---------------------- BAT- ของ Solar Controller

LOAD+ ของ Controller
    -> ฟิวส์ 1A
    -> สวิตช์หลัก
    -> แยกเป็น 2 ทาง
         ทางที่ 1 -> V+ ของเซ็นเซอร์ NPK
         ทางที่ 2 -> IN+ ของ Buck Converter

LOAD- ของ Controller
    -> GND ของเซ็นเซอร์ NPK
    -> IN- ของ Buck Converter
    -> GND ของ ESP32
    -> GND ของ MAX485

OUT+ ของ Buck = 5.0V
    -> VIN/5V ของ ESP32
    -> VCC ของ MAX485

OUT- ของ Buck
    -> GND ของ ESP32 และ MAX485
```

### ลำดับการต่อชุด Stationary

1. ยังไม่ต้องต่อ ESP32 หรือเซ็นเซอร์
2. ต่อแบตเตอรี่เข้าขั้ว `BAT+` และ `BAT-` ของ Solar Controller
3. ตรวจจอ Controller ว่าแสดงแรงดันแบตเตอรี่ถูกต้อง
4. ต่อแผงโซลาร์เข้าขั้ว `PV+` และ `PV-`
5. ต่อสาย `LOAD` ผ่านฟิวส์และสวิตช์
6. ต่อ Buck Converter เข้ากับสาย LOAD
7. ใช้มัลติมิเตอร์วัดขา `OUT+` กับ `OUT-`
8. ปรับ Buck ให้ได้ **5.0V** ก่อนเชื่อมต่อ ESP32
9. ปิดสวิตช์ แล้วต่อ ESP32, MAX485 และเซ็นเซอร์
10. เปิดสวิตช์และตรวจสอบว่าไม่มีชิ้นส่วนร้อนผิดปกติ

## ชุด Handheld: แผนผังไฟ

ถ่าน 3.7V สองก้อนต้องใช้เป็นชุด 2S พร้อม BMS และเครื่องชาร์จ 8.4V:

```text
ถ่าน 3.7V สองก้อนแบบอนุกรม
    -> BMS แบบ 2S
    -> เครื่องชาร์จ Li-ion 8.4V
    -> สวิตช์
    -> แยกเป็น 2 ทาง
         ทางที่ 1 -> เซ็นเซอร์ NPK (แรงดันต้องอยู่ในช่วง 5-30V)
         ทางที่ 2 -> Buck Converter -> 5.0V -> ESP32 และ MAX485
```

ห้ามใช้ถ่านสองก้อนโดยไม่มี BMS และห้ามต่อถ่าน 3.7V ตรงเข้ากับเซ็นเซอร์
เพราะต่ำกว่าค่าไฟขั้นต่ำ 5V หากรางถ่านต่อแบบขนาน จะได้เพียงประมาณ 3.7V
และต้องใช้ Boost Converter 5V แทน

## การต่อ ESP32 กับ MAX485

```text
ESP32 GPIO17 (TX2) -> MAX485 DI
ESP32 GPIO16 (RX2) <- MAX485 RO ผ่านตัวแบ่งแรงดัน
ESP32 GPIO4        -> MAX485 DE และ RE ต่อรวมกัน
ESP32 GND          -> MAX485 GND
ESP32 5V/VIN       -> MAX485 VCC

MAX485 A -> สายเหลืองของเซ็นเซอร์
MAX485 B -> สีน้ำเงินของเซ็นเซอร์
เซ็นเซอร์ V+ -> สีน้ำตาล
เซ็นเซอร์ GND -> สีดำ
```

### สำคัญมากสำหรับ MAX485 แบบ 5V

MAX485 หลายรุ่นทำงานที่ 5V และขา `RO` อาจส่งสัญญาณ 5V ซึ่งสูงเกินกว่าที่ GPIO
ของ ESP32 รับได้ ให้ใช้วงจรนี้:

```text
MAX485 RO -- ตัวต้านทาน 2.2kΩ --+-- ESP32 GPIO16
                                |
                              3.3kΩ
                                |
                               GND
```

ทางเลือกที่ปลอดภัยกว่า คือใช้ **MAX3485 แบบ 3.3V** ซึ่งไม่ต้องใช้ตัวแบ่งแรงดัน

## ค่า Modbus สำหรับการทดสอบครั้งแรก

สำหรับเซ็นเซอร์ NPK รุ่นที่มีลักษณะตรงกับรูป ให้เริ่มด้วย:

```text
Baud rate: 9600
รูปแบบข้อมูล: 8N1
Modbus address: 0x01
Function: 0x03

N: register 0x001E
P: register 0x001F
K: register 0x0020
```

แต่ถ้า AF333 ของคุณใช้คู่มือคนละรุ่น อาจใช้ 4800 หรือ register อื่นได้
ให้หยุดการทดสอบและขอ register table จากผู้ขายหากไม่มีข้อมูลตอบกลับ

## การทดสอบอย่างปลอดภัย

1. ต่อเฉพาะแบตเตอรี่กับ Solar Controller
2. ตรวจขั้วและแรงดันแบตเตอรี่
3. ต่อ Buck โดยยังไม่ต่อ ESP32
4. ปรับเอาต์พุต Buck เป็น 5.0V
5. ปิดไฟ
6. ต่อ ESP32 และ MAX485
7. ต่อสายเซ็นเซอร์ V+ และ GND ให้ถูกขั้ว
8. ต่อสาย A และ B
9. เปิดไฟ
10. ดูว่ามีความร้อน กลิ่นไหม้ หรือควันหรือไม่ ถ้ามีให้ปิดทันที
11. อัปโหลดไฟล์ `esp32_modbus_diagnostic.ino`
12. เปิด Serial Monitor ที่ 115200
13. ตรวจว่ามีข้อมูล RX และ CRC ถูกต้อง
14. เมื่ออ่านได้แล้วจึงใช้ firmware หลัก

ถ้าไม่มีข้อมูลตอบกลับ ให้ปิดไฟก่อน แล้วตรวจตามลำดับ:

1. แรงดันเซ็นเซอร์
2. สีน้ำตาล/ดำ
3. A/B สลับกันหรือไม่
4. Baud rate 9600 และ 4800
5. Address 0x01
6. Register table ของ AF333

## สิ่งที่ไม่ควรทำ

- ห้ามต่อ 12V เข้า ESP32
- ห้ามต่อ MAX485 `RO` 5V เข้า GPIO16 โดยตรง
- ห้ามต่อเซ็นเซอร์เข้าขา GPIO โดยตรงโดยไม่มี RS485
- ห้ามเสียบสายกลับขั้วเพื่อทดลอง
- ห้ามใช้ค่าที่ไม่มีข้อมูลเป็นความชื้นหรือ pH
- ห้ามใช้ค่า NPK เป็นคำแนะนำปุ๋ยสุดท้ายโดยไม่พิจารณาชนิดพืชและผลตรวจดิน
- ห้ามชาร์จถ่านลิเธียมด้วย Solar Controller 12V โดยไม่มีระบบ BMS ที่ถูกต้อง

## ไฟล์ firmware

- โปรแกรมอ่าน NPK สำหรับ ESP32: `firmware/esp32_soil_handheld/esp32_soil_handheld.ino`
- โปรแกรมตรวจสอบ Modbus ดิบ: `firmware/esp32_modbus_diagnostic/esp32_modbus_diagnostic.ino`
- โปรแกรมทดสอบแสดงค่า NPK บน Serial Monitor โดยไม่ใช้ Wi-Fi: `firmware/esp32_soil_serial_monitor/esp32_soil_serial_monitor.ino`

## วิธีดูค่าบน Serial Monitor แบบง่าย

สำหรับการทดสอบครั้งแรก ให้เลือกไฟล์ `esp32_soil_serial_monitor.ino` ใน Arduino IDE
แล้วเลือกบอร์ด ESP32 และพอร์ต USB จากนั้นอัปโหลด เปิด Serial Monitor ที่ **115200 baud**
จะเห็นผลลัพธ์ลักษณะนี้:

```text
N = 42 mg/kg | P = 28 mg/kg | K = 51 mg/kg
สถานะ: อ่านค่าได้
```

สเก็ตช์นี้จะลองค่ามาตรฐานหลายชุดให้อัตโนมัติ ได้แก่ baud `4800/9600/2400`,
address `1/2/3` และ register ที่พบบ่อย `0x0004/0x001E` หากยังอ่านไม่ได้ให้ตรวจ
คู่มือของเซ็นเซอร์ AF333 รุ่นจริง เพราะ register map อาจต่างกัน

## การส่งข้อมูลเข้าแอป Grow a Garden

Firmware หลักจะส่งข้อมูลตามเส้นทางนี้:

```text
AF333 -> RS485 -> ESP32 -> Wi-Fi/อินเทอร์เน็ต -> MQTT -> แอป Grow a Garden
```

ก่อนอัปโหลด ให้เปิดไฟล์ `esp32_soil_handheld.ino` และกรอก:

```cpp
const char* WIFI_SSID = "ชื่อ Wi-Fi หรือชื่อฮอตสปอต";
const char* WIFI_PASSWORD = "รหัสผ่าน";
```

ให้ปล่อย `API_URL` เป็นค่าว่างในช่วงทดสอบ เพราะแอปรับค่าจาก MQTT อยู่แล้ว
ติดตั้งไลบรารี Arduino ชื่อ `WiFiManager` ก่อนอัปโหลด หลังเปิดเครื่องครั้งแรก
ESP32 จะปล่อย Wi-Fi ชื่อ `Grow-Scout-Setup` รหัสผ่าน `growgarden` ให้โทรศัพท์เชื่อมต่อ
จากนั้นหน้า setup จะให้เลือก Wi-Fi ของบ้านหรือฮอตสปอตและกรอกรหัสผ่าน เมื่อบันทึกแล้ว
ESP32 จะจำค่าไว้เองและเชื่อมต่ออัตโนมัติในครั้งถัดไป

หลังอัปโหลด เปิด Serial Monitor ที่ `115200` และตรวจข้อความ `Wi-Fi connected`,
`MQTT connected` และ `MQTT published` ตามลำดับ

ในแอปให้เปิด `ตรวจดิน` เลือก `เครื่องพกพา` เลือกฟาร์มและจุดตรวจ เมื่อค่า NPK
ปรากฏ ให้กดบันทึกจุดพร้อม GPS ตำแหน่ง GPS จะมาจากโทรศัพท์ ส่วนค่า NPK จะมาจาก ESP32

### ใช้งานระยะไกล

- ถ้า ESP32 อยู่ไกลแต่มี Wi-Fi ที่ต่ออินเทอร์เน็ตได้ จะส่งเข้าแอปได้จากทุกระยะผ่าน MQTT
- ถ้าอยู่กลางนา ให้ใช้เราเตอร์ 4G/ซิมที่ปล่อย Wi-Fi ให้ ESP32
- ถ้าใช้ฮอตสปอตโทรศัพท์ โทรศัพท์ต้องอยู่ใกล้ ESP32 และมีอินเทอร์เน็ตมือถือ
- ถ้าไม่มี Wi-Fi หรืออินเทอร์เน็ตเลย ระบบนี้จะส่งเข้าแอปไม่ได้ ต้องเพิ่มระบบ LoRa หรือโมดูล 4G

Broker สาธารณะในโค้ดเหมาะสำหรับทดสอบเท่านั้น ข้อมูลอาจปะปนกับอุปกรณ์อื่นและไม่ควรใช้
กับข้อมูลจริงระยะยาว ก่อนใช้งานจริงควรเปลี่ยนเป็น MQTT broker ส่วนตัวที่มี username,
password และ TLS

คู่มือนี้ปรับตามเซ็นเซอร์ NPK ในรูปและระบบ ESP32 ของโครงการ Chaona
การตั้งค่า firmware ปัจจุบันเป็น NPK-only สำหรับรุ่นนี้ แต่ register และ baud rate
ต้องยืนยันด้วยคู่มือของผู้ขายหรือโปรแกรมทดสอบก่อนใช้ผลจริง หากอ่านไม่ได้ให้หยุด
และทดสอบ 9600/4800 กับ address ที่ผู้ขายระบุ อย่าเปลี่ยนสายหรือจ่ายไฟซ้ำแบบเดาสุ่ม

จากรูปยังเห็นสายเปลือยและจุดต่อที่พันเทปอยู่ จึงยังไม่ควรนำลงแปลงจนกว่าจะหุ้มฉนวน
ยึดสายให้แน่น และใส่กล่องกันน้ำ การต่อจริงควรทำทีละขั้น โดยวัดแรงดันทุกจุดก่อนเชื่อมต่อบอร์ด
